# T-Deal

> T-Deal 웹앱의 UI/UX를 직접 개선하고 퍼블리싱한 개인 프로젝트

## 프로젝트 소개

기존 T-Deal 웹앱의 화면과 사용자 경험을 분석하고,
UI/UX를 직접 개선하여 웹으로 구현한 개인 프로젝트입니다.

## 주요 작업

- 기존 화면 분석 및 UI/UX 개선
- UI 디자인 및 화면 구성 개선
- HTML/CSS 기반 웹 퍼블리싱
- 반응형 웹 구현
- 사용자 인터페이스 및 인터랙션 구현

## Tech Stack

- HTML5
- CSS3
- JavaScript

## 프로젝트 목적

실제 서비스 화면을 분석하고 개선 방향을 도출한 후,
디자인부터 웹 화면 구현까지 직접 진행하며
UI/UX 설계 및 퍼블리싱 역량을 향상시키기 위해 진행했습니다.
